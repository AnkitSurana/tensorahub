Probability Distributions

Turning real results from the bag game into a table and a chart, then generalizing to any probability distribution, table, chart, or equation, with a business example.

Where we are in the three steps

Recall the three-step process for the bag game from Chapter 4, Random Variables, in the "The bag of balls game" section:

  1. Find all the possible combinations.
  2. Find the probability of each combination.
  3. Use the probabilities to estimate the profit or loss per player.

Step 1 is done. We defined X as the number of red balls drawn, and grouped the 16 possible outcomes into 5 values of X, from 0 to 4. Now we move to step 2: finding the probability of each value of X.

Real people play the game

To find these probabilities, 75 employees played the game. For each person, we noted their result and recorded which value of X they landed on. As more people played, a chart filled up showing how many people landed on each value. This chart, with X on one axis and the count of people on the other, is called a histogram.

Here is what the histogram looked like after all 75 people had played (Figure 1):

Figure 1. Bar height is frequency, the number of people who got that value.

From frequency to probability

Recall empirical probability from Chapter 2, Probability Recap, in the "Empirical vs. theoretical probability" section: the number of times something happened, divided by the number of trials. Here, each of the 75 people who played the game is one trial, and X landing on a given value is what we are counting.

26 of the 75 people drew exactly 2 red balls. What is the probability that a random player from this group gets X = 2?

Use the frequency for X = 2 over the total number of players:

P(X = 2)= 2675is about 0.347

In plain terms, about 35% of the players who tried this game drew exactly 2 red balls.

Using the same idea for every value of X, here is the full probability distribution:

X (number of red balls)01234Total
P(X)0.0270.1600.3470.3330.1331.000

This table, showing the probability of every possible value of X, is called the probability distribution of X.

25 of the 75 people drew exactly 3 red balls. What is P(X = 3)?

Same method as before, using the frequency for X = 3:

P(X = 3)= 2575is about 0.333

In plain terms, about 33% of the players drew exactly 3 red balls.

Add up all five probabilities in the distribution: P(X=0) + P(X=1) + P(X=2) + P(X=3) + P(X=4). What do you get, and why does that make sense?

0.027 + 0.160 + 0.347 + 0.333 + 0.133 = 1.000 (allowing for a little rounding). This makes sense because every player ends up with exactly one of these five values of X. The five values cover every possibility and never overlap, so their probabilities have to add up to 1.

The probability distribution chart

Plotting these probability values against the values of X gives the probability distribution chart (Figure 2):

Figure 2. Bar height is now the probability, between 0 and 1.

Notice the bars are exactly the same shape as the histogram earlier. Only the scale on the vertical axis has changed, from raw counts of people up to 26, to probabilities between 0 and 1. Because a chart makes it easier to see how likely each value is at a glance, this bar chart form is the one most commonly used to show a probability distribution.

With this distribution in hand, we know how likely each value of X is. That is exactly what step 3 will use, to work out whether the game makes money, loses money, or breaks even for the house in the long run. Before we get there, let's look at probability distributions more generally.

Different ways to show a probability distribution

A probability distribution is any form of representation that tells us the probability for every possible value of X. It can be shown as a table, a chart, or an equation. All three show exactly the same information.

For example, take a variable X that can be 1, 2, 3, 4, 5, or 6, where P(x) = x ÷ 21 for each of those values. (A quick notation note: capital X is the random variable itself, and lowercase x stands for one specific value it can take, this is why you will see both used together.) As a table:

x123456
P(x)1/212/213/214/215/216/21

As a chart, using the decimal value of each fraction (Figure 3):

Figure 3. The distribution P(x) = x ÷ 21, x = 1 through 6, plotted as a bar chart.

And as an equation:

P(x) = x ÷ 21, for x = 1, 2, 3, 4, 5, and 6

Using the equation P(x) = x ÷ 21, check that it agrees with the table and chart for x = 4.

Put x = 4 into the equation:

P(4)= 421is about 0.190

This matches 4/21 in the table, and the 0.190 bar in the chart (Figure 3). All three forms are just different views of the same numbers.

What makes a probability distribution valid?

A valid, complete probability distribution follows two rules, and both come straight from the basic definition of probability:

  • No probability value can be negative.
  • All the probability values must add up to 1.

Check the distribution P(x) = x ÷ 21 for x = 1 through 6 against both rules. Is it a valid probability distribution?

Every value of x is positive, so every P(x) is positive too, no negatives. Adding all six values:

121+ 221+ 321+ 421+ 521+ 621= 2121= 1

Both rules hold, so yes, this is a valid probability distribution.

As we saw earlier with the bag game, a probability distribution and the frequency distribution (histogram) it comes from are exactly the same shape. Only the scale on the vertical axis changes, from raw counts to probabilities between 0 and 1.

A business example: will the project make a profit?

A company's management is deciding whether to invest in a project. Whether the project makes a profit depends on the economic cycle at the time, such as a recession, a normal economy, or a boom. Based on expert opinions, here is the probability of each economic cycle:

Economic cycleProbability
Recession0.1
Normal0.7
Boom0.2

As an analyst, you are asked: can the company expect to make a profit? Should it invest? In this form, the table does not answer that, since "Recession", "Normal", and "Boom" are just labels, not numbers. So you quantify it with a random variable. Since profit is what you care about, define X as the net revenue of the project.

A colleague works out the net revenue for each economic cycle, and builds this probability distribution for X:

X (net revenue, ₹ crores)P(x)
−3050.1
+150.7
+950.2

According to the experts' table, what is the probability the economy is in a boom?

Read it straight off the table: 0.2.

If the economy turns out to be a recession, what value does X (the net revenue) take, and with what probability?

A recession has probability 0.1 in the first table. That same 0.1 lines up with X = −305 in the net revenue table, since a recession is what causes that loss. So X = −₹305 crore, with probability 0.1.

Check the net revenue distribution against the two rules for a valid probability distribution. Does it hold up?

No probability is negative (0.1, 0.7, and 0.2 are all positive, even though one of the X values, −305, is negative). Adding the probabilities: 0.1 + 0.7 + 0.2 = 1. Both rules hold, so this is a valid probability distribution.

Now you have a full probability distribution for X, the net revenue of the project. To finally answer whether the company should expect a profit or a loss, you need one more idea: expected value. That is what comes next.
