The Standard Normal Distribution

Turning any normal variable into a "how many standard deviations from the mean" Z-score, why that reframing makes any normal probability question look the same, and how to answer any of them with a single reference table.

What actually matters: how far from the mean, in units of σ

Recall from Chapter 16, The Normal Distribution, in the "The 1-2-3 rule" section, that every probability we found came from measuring how far X was from the mean μ, in units of the standard deviation σ. The specific numbers for μ and σ never mattered on their own: 25 to 45 with μ = 35, σ = 5 gave the same 95% as μ − 2σ to μ + 2σ would with any other mean and standard deviation.

So the useful question is not "what is X?" but "how many standard deviations away from the mean is X?" Let us make that a proper number.

Take a normal variable with μ = 35 and σ = 5. If X = 43.25, how many standard deviations is X above the mean?

First find the raw distance from the mean:

X − μ = 43.25 − 35= 8.25

Then divide by σ to express that distance in units of standard deviations:

8.255= 1.65

So X = 43.25 is 1.65 standard deviations above the mean. This value, 1.65, is called the Z-score of X.

The Z-score formula

In general, for any normal variable X with mean μ and standard deviation σ, the Z-score is:

Z= X − μσ

Read it aloud as "Z equals X minus mu, over sigma". It says: subtract the mean, then measure in units of the standard deviation. Z itself is a new random variable, called the standardized normal variable. It carries all the same information as X but drops the specific μ and σ from the picture.

What Z looks like: the standard normal distribution

Because Z is just X rescaled, it is also normally distributed. Its own mean is 0 (since Z = 0 when X = μ) and its own standard deviation is 1 (since one unit of Z is one σ of X). This particular normal distribution, with mean 0 and standard deviation 1, is called the standard normal distribution. Figure 1 shows it:

Figure 1. The standard normal distribution: a normal curve with mean 0 and standard deviation 1. The horizontal axis is Z, in units of standard deviations from the mean.

Sanity-checking with the 1-2-3 rule

Since Z just rescales X, every 1-2-3 rule probability from Chapter 16 must still hold, just written in Z. Take the three worked examples from the "Using the 1-2-3 rule to compute probabilities" section of Chapter 16, and translate each range into Z:

Range in X (μ = 35, σ = 5)Same range in ZProbability
25 ≤ X ≤ 45−2 ≤ Z ≤ 295%
25 ≤ X ≤ 50−2 ≤ Z ≤ 397.35%
X < 40Z < 184%

Each row's Z range comes from applying Z = (X − μ)/σ to the endpoints of the X range. The probabilities are unchanged from Chapter 16.

Notice something important: the middle column (in Z) does not mention 35 or 5 at all. Every probability question about any normal distribution reduces to the same set of questions about Z. That is the payoff of standardising: one table of Z probabilities is enough to handle any normal distribution.

Each cell is P(Z ≤ z). To look up a Z of, say, 1.65: find the row 1.6, then the column .05, and read off .9505. Cells highlighted in brass are the ones used in the worked examples below. A full-resolution PDF version is at math.arizona.edu/~rsims/ma464/standardnormaltable.pdf.

Negative Z values. This table only lists positive Z. For a negative Z, use the fact that the standard normal is symmetric about 0:

P(Z ≤ −z) = 1 − P(Z ≤ z)

For example, P(Z ≤ −1.96) = 1 − P(Z ≤ 1.96) = 1 − 0.9750 = 0.0250. This one identity replaces the need for a second table.

Reading the Z-table: a first worked example

Using the Z-table above, find P(Z ≤ 0.68).

Split 0.68 into two parts: the row is the value up to the first decimal (0.6), and the column is the second decimal (.08). At the intersection of row 0.6 and column .08, read the value .7517.

P(Z ≤ 0.68)= 0.7517

So about 75.17% of a standard normal variable falls at or below 0.68.

Figure 2 shows what P(Z ≤ z) actually means: the area under the standard normal PDF from the far left up to z. For z = 0.68, that area is 0.7517.

Applying it to a real X: commute time

Now put the two pieces together. Suppose the average commute time of an employee is normally distributed with mean 35 minutes and standard deviation 5 minutes. What is the probability that a randomly picked employee's commute is less than 43.25 minutes?

With μ = 35 and σ = 5, find P(X < 43.25).

Step 1. Convert 43.25 into a Z-score using Z = (X − μ)/σ:

Z= 43.25 − 355 = 8.255 = 1.65

Step 2. Look up P(Z ≤ 1.65) in the Z-table above. Row 1.6, column .05, gives .9505.

P(X < 43.25) = P(Z < 1.65)= 0.9505

So about 95% of employees have a commute time under 43.25 minutes.

Applying it to a two-sided range

The same idea handles a range like "between two values". Convert both endpoints to Z, look up each cumulative probability, and subtract.

With μ = 35 and σ = 5, find P(25.2 ≤ X ≤ 44.8).

Step 1. Convert both endpoints to Z-scores:

lower Z= 25.2 − 355 = −9.85 = −1.96
upper Z= 44.8 − 355 = 9.85 = 1.96

Step 2. Look up each cumulative probability. For Z = 1.96, row 1.9 column .06 gives .9750:

P(Z ≤ 1.96)= 0.9750

For Z = −1.96, the table only has positive values, so use symmetry:

P(Z ≤ −1.96) = 1 − P(Z ≤ 1.96) = 1 − 0.9750= 0.0250

Step 3. Subtract the smaller cumulative from the larger to get the range probability, using the range formula from Chapter 11, Cumulative Probability Distributions, in the "Using cumulative probability to find a range" section:

P(25.2 ≤ X ≤ 44.8) = 0.9750 − 0.0250= 0.95

So 95% of commute times fall between 25.2 and 44.8 minutes. Figure 3 shows this as the middle 95% area:

Figure 3. The middle 95% of the standard normal falls between Z = −1.96 and Z = 1.96. This is a slightly tighter version of the 1-2-3 rule's 2σ band, which gives approximately 95%: 1.96 is the exact Z value corresponding to 95%.

The workflow for any normal probability question is the same three steps: (1) convert the X endpoints to Z-scores using (X − μ)/σ, (2) look each Z up in the table (using symmetry for negative Z), and (3) combine them the same way you would combine any two cumulative probabilities: F(b) − F(a) for a range, 1 − F(a) for "above a", F(a) itself for "below a".
