Probability Density Functions

Why exact-value probability does not work for continuous variables, how the cumulative distribution function looks for one, and how the probability density function tells the same story as an area.

The problem: a continuous variable

Imagine you work at a company with 3000 employees in the local office, and you want to study each employee's daily commute time: how long, in minutes, it takes them to get to work. Unlike the number of red balls in the bag game from earlier chapters, commute time is a continuous random variable. It can be 32 minutes, or 32.4 minutes, or 32.417 minutes, and there is no reason to stop at any particular number of decimal places.

What is the probability that an employee's commute time is exactly 35 minutes?

Very close to 0. Because commute time is continuous, there are effectively infinite possible values a single measurement can land on: 35.00, 35.01, 35.001, 35.0001, and so on. The chance of landing on any one exact value out of an infinite list is essentially 0.

This is the first thing to understand about continuous random variables: asking for the probability of an exact value is not useful, because that probability is always effectively 0. So why talk about probability for continuous variables at all?

Talk about ranges, not exact values

The fix is simple: instead of asking for the probability of an exact value, ask for the probability of a range of values. "What is the probability that the commute time is between 35 and 40 minutes?" is a meaningful question, even though "exactly 35 minutes" is not.

Suppose the company has done a study and produced this table for its 3000 employees, showing the probability of the commute time falling in each 5-minute range:

Commute time (minutes)Probability
20 to 250.15
25 to 300.20
30 to 350.30
35 to 400.20
40 to 450.15

The five range probabilities add up to 0.15 + 0.20 + 0.30 + 0.20 + 0.15 = 1.00, as they must, since every employee's commute time falls into exactly one of these ranges.

Building the cumulative probabilities

Recall from Chapter 11, Cumulative Probability Distributions, in the "Defining cumulative probability" section, that the cumulative probability F(x) is P(X ≤ x), the probability that X takes any value up to and including x.

Using the table above, we can find the cumulative probability at the top of each range. The probability of the commute time being 25 or less is just the first row (nothing smaller in the table):

F(25) = 0.15

For 30 or less, add the first two rows:

F(30) = 0.15 + 0.20=0.35

Using the same method, find F(35), the probability that the commute time is 35 minutes or less.

Add the first three rows of the table:

F(35) = 0.15 + 0.20 + 0.30=0.65

So there is a 65% chance that a randomly picked employee's commute is 35 minutes or less.

Continuing the same way for 40 and 45:

F(40) = 0.15 + 0.20 + 0.30 + 0.20=0.85
F(45) = 0.15 + 0.20 + 0.30 + 0.20 + 0.15=1.00

The CDF as a smooth curve

Plotting these cumulative probabilities against x gives the cumulative distribution function, or CDF, shown in Figure 1. For a continuous variable, the plot is a smooth curve, not a bar chart. This is because the commute time can take any value between 20 and 45, not just the six values in the table above. The dots mark the six values we calculated, and the curve smoothly connects them.

Figure 1. The CDF for the commute time. The curve is smooth because commute time is continuous: every value between 20 and 45 has some cumulative probability, not just the six we calculated.

Two properties of any CDF

Two things are worth noticing about the curve in Figure 1:

  1. It never decreases. Moving from left to right, the curve either stays flat or goes up. This is because F(x) is a cumulative sum of probabilities, and probabilities are never negative, so adding more of them can only grow the total or leave it unchanged. Formally, a CDF is a monotonically non-decreasing function.
  2. It approaches 1 at the far right. Once x is large enough to cover every possible value the variable can take, F(x) equals 1, because "X is that value or less" is then guaranteed. On this chart, F(45) = 1 exactly, since no employee has a commute longer than 45 minutes in this study.

The probability density function

The CDF gives one way to answer "what is the probability that X is at most x?" There is a second, closely related function that answers the same question but in a different visual form: the probability density function, or PDF.

A PDF is a curve where the area under the curve, between two values on the horizontal axis, equals the probability that the variable falls in that range. So if you want the cumulative probability F(x), which is P(X ≤ x), you find the area under the PDF from the smallest possible value of X up to x.

How the PDF is built from the interval table

Before drawing the PDF, we need to know its height at each x. That height is called the probability density at x. It is not a probability by itself, it is a probability per unit of x. In one line:

probability density = probability in a range ÷ width of that range

Applied to the interval table earlier in this chapter, each of the five 5-minute bins gives its own density: just divide the bin's probability by its width (5 minutes):

Bin (minutes)ProbabilityDensity = probability ÷ 5
20 to 250.150.15 ÷ 5 = 0.030
25 to 300.200.20 ÷ 5 = 0.040
30 to 350.300.30 ÷ 5 = 0.060
35 to 400.200.20 ÷ 5 = 0.040
40 to 450.150.15 ÷ 5 = 0.030

Each row's density is just the row above's probability divided by its 5-minute width. Notice the density is highest in the middle (0.060 for 30 to 35 minutes) and lower at the tails: this is what makes the PDF bell-shaped.

To turn these five density values into a smooth PDF curve, plot each one at the middle of its bin (22.5, 27.5, 32.5, 37.5, 42.5) and connect them with a smooth line that tapers to 0 at 20 and 45 (the smallest and largest commute times). The resulting curve is what a real, continuous distribution would look like if the company had collected finer-grained data than 5-minute bins.

Two sanity checks about the shape:

  1. The peak sits over the biggest-probability bin. Since 30 to 35 is the most likely range (0.30), the density there is highest (0.060), and the curve peaks around x = 32.5.
  2. The total area under the curve is 1. Every 5-minute strip has area = density × 5 = original probability, and those five probabilities add up to 0.15 + 0.20 + 0.30 + 0.20 + 0.15 = 1.00.

Now take the commute-time example we already used for the CDF. Say we want the cumulative probability at x = 28, in other words F(28). Figure 2 shows both ways to find it side by side: read the shaded area under the PDF (left), or read the y-value off the CDF (right). Both give the same answer, about 0.28.

Figure 2. The same commute-time distribution shown two ways. Left: the PDF, where the shaded area from 20 to 28 equals the cumulative probability F(28). Right: the CDF, where F(28) is just the y-value at x = 28. Both read as about 0.28.

Two visual forms of the same information: the CDF shows the cumulative probability as a y-value, and the PDF shows it as an area under the curve.

Using the PDF in Figure 2, how would you find the probability that a randomly picked employee's commute time is between 30 and 35 minutes?

Find the area under the PDF curve between x = 30 and x = 35. From the table earlier in this chapter, that area is 0.30, matching the "30 to 35" row directly.

The same range probability can also be read off the CDF as F(35) − F(30) = 0.65 − 0.35 = 0.30, using the range formula from Chapter 11.

Why we use CDFs and PDFs for continuous variables

Both the CDF and the PDF describe probability in terms of intervals: F(x) covers everything up to x, and the area under the PDF between two limits covers everything in that range. That is exactly the right fit for a continuous variable, where "the probability of an exact value" is always 0 and only range probabilities carry information.

For a discrete variable, on the other hand, the exact-value probability P(X = k) is a real, useful number, so a bar chart of those probabilities (one bar per possible value) is the natural way to show the distribution. That is the form we used in Chapter 5, Probability Distributions, and again in Chapter 10, Binomial Distribution.

Continuous vs discrete CDFs

The CDF exists for discrete variables too, not just continuous ones. But it looks very different: a bar chart, not a smooth curve. Compare Figure 1 above (continuous, smooth curve) to Figure 3 below (discrete, bar chart) for the bag game from Chapter 11:

Figure 3. The CDF for the discrete bag game from Chapter 11: one bar per possible value of X. Compare with Figure 1's smooth curve.

The reason the discrete CDF is drawn as a bar chart, and the continuous CDF as a smooth curve, is that the cumulative probability behaves very differently in the two cases.

In the discrete bag game, X can only take the values 0, 1, 2, 3, or 4. The cumulative probability is flat between any two consecutive values: F(3) = 0.8704, and F(3.5), F(3.999), F(3.9999999) are also all 0.8704, because none of those values are possible outcomes of the game, so nothing new gets added to the running total until you cross the next possible value at x = 4. Drawing this as five discrete bars, one per possible value, captures the fact that only those five values matter.

In the continuous commute-time case, the situation is different. Every value of x between 20 and 45 corresponds to some cumulative probability, and each nudges the total up a little. F(21) is different from F(21.1), which is different from F(21.2), and so on. A smooth curve is the natural shape for a value that changes at every single x.

In the discrete bag game, what is F(2.7)?

F(2.7) is P(X ≤ 2.7), the probability that X is at most 2.7. Since X can only be 0, 1, 2, 3, or 4, "at most 2.7" is the same as "at most 2", so F(2.7) = F(2) = 0.5248. This is the flatness we described above: F does not change between the possible values.
