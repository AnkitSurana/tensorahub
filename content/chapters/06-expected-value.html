Expected Value

What a random variable takes "on average," and how to use it to judge whether a game, a bet, or a project is worth it.

Where we are in the three steps

Recall the three-step process for the bag game from Chapter 4, Random Variables, in the "The bag of balls game" section:

  1. Find all the possible combinations.
  2. Find the probability of each combination.
  3. Use the probabilities to estimate the profit or loss per player.

Steps 1 and 2 are done. We defined X as the number of red balls, and found its probability distribution: P(0) = 0.027, P(1) = 0.160, P(2) = 0.347, P(3) = 0.333, and P(4) = 0.133. Now, step 3, we use these probabilities to work out what a player should expect from this game.

Imagine 1000 people play the game

Suppose 1000 people play the bag game. How many of them would you expect to land on each value of X? Multiply each probability by 1000:

So about 160 of the 1000 players would draw exactly 1 red ball.

How many red balls in total?

Across all 1000 people, how many red balls were drawn in total? The 27 people who drew 0 red balls contribute 0 red balls each. The 160 people who drew 1 red ball contribute 1 each. The 347 people who drew 2 contribute 2 each, and so on. Add up every group's contribution:

27 + 160 + 347 + 333 + 133 = 1000. Yes, every player falls into exactly one of the five groups, so they add up to the full 1000.

The formal definition of expected value

The expected value of a random variable X is the value you would "expect" to get after performing the experiment once. It is also called the expectation, the average, or the mean value. If X can take the values x1, x2, up to xn, the expected value, written E(X), is:

E(X) = x1 · P(x1) + x2 · P(x2) + ... + xn · P(xn)

In words: take every value X can be, multiply it by the probability of that value, and add up all those products.

Getting 2.385 directly from the probabilities

You do not actually need to imagine 1000 players. The same answer comes straight from the formula, using the probability distribution of X directly:

E(X)= (0 × 0.027) + (1 × 0.160) + (2 × 0.347) + (3 × 0.333) + (4 × 0.133)

Work out E(X) term by term using the probabilities P(0) = 0.027, P(1) = 0.160, P(2) = 0.347, P(3) = 0.333, and P(4) = 0.133.

Multiply each value of X by its own probability:

0 × 0.027 = 0 1 × 0.160 = 0.160 2 × 0.347 = 0.694
3 × 0.333 = 0.999 4 × 0.133 = 0.532

Now add up all five products:

0 + 0.160 + 0.694 + 0.999 + 0.532= 2.385

This is the same 2.385 we found by imagining 1000 players. The formula is just a shortcut that skips the "imagine 1000 people" step and works directly off the probabilities.

So the expected value of X is 2.385. A player can expect to draw about 2.385 red balls per game, on average.

What does 2.385 actually mean?

You can never actually draw 2.385 red balls in one game. You always get a whole number: 0, 1, 2, 3, or 4. So what does an expected value of 2.385 actually mean?

It means that if you played this game an infinite number of times, the average number of red balls per game, across all those games, would settle at 2.385. It is a long-run average, not a result you should expect on any single attempt. Figure 1 shows where this value falls.

Figure 1. X can only ever land exactly on 0, 1, 2, 3, or 4. E(X) sits between 2 and 3, a value X itself can never actually take.

This is not unusual. Expected values often land on a number the random variable itself can never take.

You throw a fair die once and let X be the number that comes up. What is E(X)?

X can be 1, 2, 3, 4, 5, or 6, each with probability 1/6. Add up value times probability for all six:

E(X)= 1 + 2 + 3 + 4 + 5 + 66= 216= 3.5

A die can never actually show 3.5. Just like the bag game, this is the long-run average if you rolled the die over and over, not a single-roll result.

A better random variable: the money won

Knowing you can expect 2.385 red balls per game still does not tell us whether the house makes or loses money. Red balls are not what gets paid out, money is. So define a new random variable: let Y be the amount of money a player wins from playing the game once.

Y can only take two values:

  • Y = +₹150, if the player wins (draws 4 red balls).
  • Y = −₹10, if the player loses (draws 0, 1, 2, or 3 red balls).

We already know P(X = 4) = 0.133, so P(Y = +150) = 0.133. Losing covers every other outcome, so P(Y = −10) is the sum of the other four probabilities:

0.027 + 0.160 + 0.347 + 0.333= 0.867

Check that P(Y = +150) and P(Y = −10) add up to 1, as they should for a valid probability distribution.

0.133 + 0.867 = 1.000. Since winning and losing cover every possible outcome of the game, and Y can only be one of these two values, they must add up to 1.

Expected value of the money

Now apply the same expected value formula to Y:

E(Y) = (150 × 0.133) + (−10 × 0.867)
150 × 0.133 = 19.95 −10 × 0.867 = −8.67
19.95 − 8.67= ₹11.28

E(Y) came out to +₹11.28. Is that a good result for the house running this game?

No, it is bad for the house. A positive expected value here means the average player wins ₹11.28 per game. If many people play, the house pays out more than it collects, on average, and loses money in the long run.

For the house to be profitable, the expected value of the player's winnings needs to be negative, so that the average player loses money and the house gains it. There are a few ways to make E(Y) negative: reduce the prize money, increase the penalty for losing, or reduce the player's chances of winning. This is exactly how real casino games are designed: the game's rules are set so that a player's expected winnings always work out negative.

Back to the business example: expected return

Recall the project the company was deciding whether to invest in, from Chapter 5, Probability Distributions, in the "A business example: will the project make a profit?" section. We built this probability distribution for X, the net revenue of the project:

The expected value of X here is also called the expected return. Apply the same formula, first with the general notation, then with the actual numbers plugged in:

E(X) = (−305) · P(X = −305) + (+15) · P(X = +15) + (+95) · P(X = +95)
E(X) = (−305 × 0.1) + (15 × 0.7) + (95 × 0.2)

Work out the expected return E(X) for the project, term by term.

Multiply each net revenue value by its own probability:

−305 × 0.1 = −30.5 15 × 0.7 = 10.5 95 × 0.2 = 19

Now add up all three:

−30.5 + 10.5 + 19= −1

The expected return is −₹1 crore. Since it is negative, the project is not worth investing in: on average, across many similar projects under this same mix of economic outcomes, it would lose money rather than make it.

This is the real value of expected value: it lets you weigh every possible outcome against how likely it is, and boil an uncertain situation down to a single number you can act on, whether that is a bag game, a casino, or a company deciding where to invest.
