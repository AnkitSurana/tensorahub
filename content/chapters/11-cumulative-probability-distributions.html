Cumulative Probability Distributions

Moving from "what is the probability of exactly this value" to "what is the probability of this value or less", and why that question turns out to be more useful in practice.

A different kind of question

So far, every probability we calculated answered a question like "what is the probability that X is exactly this value?" For our bag game, we found P(X = 4), the probability of drawing all 4 red balls exactly.

But some real questions are not about an exact value. Think about the bag game from the house's side. A player only wins if they draw all 4 red balls. Any other result, drawing 3 red balls or fewer, means the player loses, and the house keeps the money. The house does not care about each exact outcome separately. It only cares about one thing: what is the probability that a player draws 3 or fewer red balls?

This "at most this many" kind of question comes up often outside bag games too. For example: what is the probability that an employee gets to work in less than 40 minutes? Nobody asks for the probability of taking exactly 40.00 minutes. They ask about a range, everything up to some limit.

This chapter is about exactly that: a way to answer "at most this value" questions directly, called the cumulative probability distribution.

Defining cumulative probability

The cumulative probability of a random variable X, written F(x), is defined as the probability that X takes a value less than or equal to x:

F(x) = P(X ≤ x)

For example, F(4) means P(X ≤ 4), the probability that X is 4 or less. F(3) means P(X ≤ 3), the probability that X is 3 or less, and so on for any value of x.

Building the cumulative table for our bag game

Recall from Chapter 10, Binomial Distribution, in the "The full generalized formula" section, the individual probabilities for our bag game, where P = 0.6 and 4 balls are drawn:

P(X)0.02560.15360.34560.34560.1296

To build the cumulative distribution, add these individual probabilities up, one value at a time, running from X = 0 upward.

F(0) is just the individual probability of X = 0, since there is nothing smaller to add:

F(0) = 0.0256

Before reading on, try finding F(1) yourself. This one is not graded, it is just to get you thinking about the approach.

F(1) means P(X ≤ 1), the probability that X is 0 or 1. Add the individual probabilities for those two values:

F(1) = 0.0256 + 0.1536=0.1792

Keep going the same way. F(2) adds one more value on top of F(1):

F(2) = 0.0256 + 0.1536 + 0.3456=0.5248

F(3):

F(3) = 0.0256 + 0.1536 + 0.3456 + 0.3456=0.8704

And F(4), adding in the last remaining value:

F(4) = 0.0256 + 0.1536 + 0.3456 + 0.3456 + 0.1296=1.0000

Putting all five together gives the full cumulative probability distribution:

x01234
F(x) = P(X ≤ x)0.02560.17920.52480.87041.0000

A property worth noticing

Look at F(4) in the table above: it comes out to exactly 1.0000. This is not a coincidence specific to this example. 4 is the largest possible value X can take in this game, so P(X ≤ 4) covers every single possible outcome. The probability of "some outcome or another happening" is always 1, so the cumulative probability at the largest possible value of X is always 1, no matter what the individual probabilities look like.

Back to the house's question

Recall the actual question from earlier: what is the probability that a player draws 3 or fewer red balls, and therefore loses? That is exactly P(X ≤ 3), which is F(3):

P(losing) = F(3) = 0.8704

So the house wins about 87% of the time. Notice this could also have been found a shorter way: since F(4) must equal 1, and winning (X = 4) and losing (X ≤ 3) cover every possibility between them, F(3) = 1 − P(X = 4) = 1 − 0.1296 = 0.8704. Same answer, just approaching it from the other direction.

Using cumulative probability to find a range

Cumulative probability is also useful for finding the probability that X falls in a range, not just "at most" some value. Suppose a company has recorded the weights of its employees (in kg), and worked out this cumulative probability distribution:

x (weight, kg)F(x) = P(X ≤ x)
500.167
550.250
600.367
650.467
700.550
750.650
800.733
850.833
900.933
950.967
1001.000

Each row reads as "the probability that an employee weighs at most x kg is F(x)." At x = 100, F(x) = 1.000, since no employee weighs more than 100 kg.

Say we want the probability that a randomly picked employee weighs between 60 and 65 kg. Two values from the table are relevant: F(60) = 0.367 and F(65) = 0.467.

How would you find P(60 ≤ X ≤ 65) using only F(60) and F(65)?

F(65) already includes everyone weighing 65 kg or less, which includes everyone weighing 60 kg or less too. To get just the part between 60 and 65, subtract away the part you do not want:

P(60 ≤ X ≤ 65) = F(65) − F(60) = 0.467 − 0.367=0.1

So there is a 0.1, or 10%, probability that a randomly picked employee weighs between 60 and 65 kg. This "subtract one cumulative value from another" technique works for finding the probability of any range, once you already know the cumulative distribution.

Cumulative probability distributions will come up again soon, when we move from discrete random variables like this bag game to continuous random variables, where a value can fall anywhere along a continuous scale instead of a fixed list of outcomes.
