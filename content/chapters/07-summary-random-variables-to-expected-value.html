Summary: Random Variables to Expected Value

A short recap of the bag game arc: turning outcomes into a random variable, building its probability distribution, and using expected value to judge the game.

Quantifying outcomes with a random variable (from Chapter 4, Random Variables)

We quantified the outcomes of the bag game by defining X as the number of red balls drawn in one game. To find X, count how many of the 4 draws are red. Two of the 16 outcomes, as examples:

  • Blue, red, red, red: 3 of the 4 draws are red, so X = 3.
  • Blue, red, blue, red: 2 of the 4 draws are red, so X = 2.

Every one of the 16 possible outcomes maps to one of five values, X = 0 through 4, this way. (For the full position-by-position breakdown of how each outcome is counted, see Chapter 4.)

Expected value, and a compact way to write it (from Chapter 6, Expected Value)

The expected value of X, using its probability distribution, is:

E(X) = x1 · P(x1) + x2 · P(x2) + ... + xn · P(xn)

The same formula is often written more compactly using a summation sign (Σ):

E(X) = Σi=1n xi · P(X = xi)

This just means: for every i from 1 to n, multiply xi by P(X = xi), and add up all those products. It is the exact same calculation as the expanded version above, just written more compactly.

For our bag game, X takes 5 values (n = 5): 0, 1, 2, 3, and 4. Write out the summation formula term by term, and confirm it matches the expanded version.

Expanding Σ for i = 1 through 5 gives exactly:

(0 × 0.027) + (1 × 0.160) + (2 × 0.347) + (3 × 0.333) + (4 × 0.133)= 2.385

Same five terms, same answer, 2.385. The summation sign is just shorthand for writing out this same sum.

What we concluded about the game (from Chapter 6, Expected Value)

Number of red balls was not the random variable that answered our original question, since red balls are not what gets paid out. So we defined a new random variable, Y, for the money a player wins after playing the game once: +₹150 if they win, −₹10 if they lose.

Using the expected value formula on Y gave:

E(Y) = +₹11.28

In other words, if the game were played an infinite number of times, the average player would come out ₹11.28 ahead. Since this is positive, the game favors the players, not the house. To turn it around, the house would need to make E(Y) negative, by decreasing the prize money, increasing the penalty, or both. A negative expected value means that, on average, a player loses money, and the house profits.

The same idea applied to a business decision (from Chapter 5 and Chapter 6)

The same three ideas, quantify with a random variable, build its probability distribution, then take the expected value, also answered a completely different question: whether a company should invest in a project. We had this probability distribution for X, the net revenue of the project:

E(X) = (−305) · P(X = −305) + (+15) · P(X = +15) + (+95) · P(X = +95)
E(X) = (−305 × 0.1) + (15 × 0.7) + (95 × 0.2) = −1 crore rupees

The expected return came out negative, so the project is expected to lose money on average, and is not worth investing in. Whether it is a bag game or a business decision, a negative expected value points the same way: away from it.
